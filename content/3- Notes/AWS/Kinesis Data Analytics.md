You can use Kinesis Data Analytics to transform and analyze streaming data in real-time with Apache Flink. 

Kinesis Data Analytics enables you to quickly build end-to-end stream processing applications for log analytics, clickstream analytics, Internet of Things (IoT), ad tech, gaming, etc. 

The four most common use cases are:
- Streaming extract-transform-load (ETL)
- Continuous metric generation
- Responsive real-time analytics
- Interactive querying of data streams. 

Kinesis Data Analytics for Apache Flink applications provides your application 50 GB of running application storage per Kinesis Processing Unit (KPU).
