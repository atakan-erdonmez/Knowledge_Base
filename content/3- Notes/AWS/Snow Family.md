It is a physical device that Amazon sends for edge computing. There is storage and compute optimized variations.
- It is used for offline data transfer, instead of using internet
- You can also use it for edge computing, using it like a server, running EC2 or Lambda 
- Use: preprocess, data, machine learning, transcoding media etc


> You cannot directly copy data to [[S3]] Glacier, you need lifecycle policy
