
AWS Systems Manager (SSM) is a centralized management service that **provides complete visibility and control over your infrastructure** across AWS cloud instances, on-premises servers, and edge devices via a lightweight installed agent. 

Its primary purpose is to **streamline and automate complex, repetitive operational tasks** at scale—such as bulk OS patching, executing remote shell scripts without maintaining bastion hosts or SSH keys (via Session Manager and Run Command), tracking software inventories, and securely **storing application configurations and secrets (via Parameter Store)**—ultimately ensuring fleet-wide security, compliance, and configuration consistency from a single interface.

# AWS Systems Manager Inventory
AWS Systems Manager Inventory is designed to collect instance metadata and configuration data, such as installed applications and OS details


# SSM Parameter Store
Secure storage for configs and secrets. Serverless, scalable, durable SDK
