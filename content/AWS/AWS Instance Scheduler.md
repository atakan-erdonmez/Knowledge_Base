It is an AWS provided, automated solution that helps you reduce costs by automatically starting and stopping non-production [[EC2]] and [[RDS]] instances on a schedule.

It is for shutting down EC2 and RDS when not in used, like on weekends.

It is not a service, but a solution that can be deployed using [[CloudFormation]]
