AWS IAM Access Analyzer helps **identify resources shared with external entities** by analyzing resource-based policies (e.g., S3 buckets, KMS keys, SNS topics, IAM roles) and detecting unintended access. 

It uses automated reasoning to evaluate the effects of policies and determines if a resource is accessible from outside the account or organization. Access Analyzer also supports policy validation, helping administrators craft secure and compliant access policies. 

It’s purpose-built for detecting and auditing external access paths to resources.
